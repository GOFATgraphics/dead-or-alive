# Server fonts

Used only by the server to draw share cards and automatic stamps (not served to browsers).

- `plus-jakarta-sans-800.woff2`: Plus Jakarta Sans ExtraBold (800), Latin subset, from Fontsource 5.3.0. Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans). SIL Open Font License 1.1 (https://openfontlicense.org).

The regular weights come from `public/fonts`, which has its own license note.
