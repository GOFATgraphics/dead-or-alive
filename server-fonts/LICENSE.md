# Server fonts

Used only by the server to draw share cards and automatic stamps (not served to browsers).
All are Latin subsets from Fontsource 5.3.0, under the SIL Open Font License 1.1 (https://openfontlicense.org).

- `plus-jakarta-sans-700.woff2`, `plus-jakarta-sans-800.woff2`: Plus Jakarta Sans Bold and ExtraBold. Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans).
- `ibm-plex-mono-700.woff2`: IBM Plex Mono Bold. Copyright 2017 IBM Corp.

The regular weights come from `public/fonts`, which has its own license note.
