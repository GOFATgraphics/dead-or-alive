# Fonts

Self-hosted Latin subsets from Google Fonts. All are under the SIL Open Font License 1.1 (https://openfontlicense.org).

- `plus-jakarta-sans-latin-v12.woff2`: Plus Jakarta Sans, variable weight 400 to 800. Tokotype.
- `ibm-plex-mono-500-latin-v20.woff2`: IBM Plex Mono Medium. IBM.
- `caveat-600-latin-v23.woff2`: Caveat SemiBold, for the handwritten sticky note on the homepage. Impallari Type.

File names carry the upstream version so they can be cached forever. Change the name when you replace a file.
