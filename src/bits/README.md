# React Bits

Components copied unchanged from [React Bits](https://reactbits.dev) ([source](https://github.com/DavidHDev/react-bits)), MIT + Commons Clause.

| Component | Used for |
|---|---|
| BlurText | Headlines blur in. |
| DecryptedText | Verdict words scramble, then resolve. Dead or alive until someone looks. |
| AnimatedContent | Specimen cards and the stamped screenshot drop in. |
| GlareHover | Glare across the stamped screenshot. |
| Magnet | Main buttons lean toward the cursor. |
| ClickSpark | Ink sparks on click. |
| StatusMark | "Box is looking" status after checkout and while a stamp loads. |

The homepage does not load these; it uses plain-JavaScript ports in `src/home.js` to keep its bundle small.

Update one by copying the new file over it. Do not edit these files. Style them from `src/styles.css`.
